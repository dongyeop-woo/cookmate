요잘알 (Yojalal)

AI가 오늘 메뉴를 추천해주는 레시피 앱

앱 소개

요잘알은 "오늘 뭐 먹지?"를 고민하는 사람들을 위한 AI 기반 레시피 앱입니다. 냉장고에 있는 재료, 그날의 기분, 가능한 조리 시간 — 무엇이든 편하게 입력하면 AI 셰프가 어울리는 요리를 추천하고, 단계별 쿠킹 가이드로 완성까지 도와줍니다.

주요 기능

  • AI 레시피 추천 — 자연어 입력 기반 맞춤 추천 (Gemini)
  • 스마트 냉장고 — 보유 재료를 추천에 자동 반영
  • 쿠킹 모드 — 단계별 가이드 + 자동 타이머 + 음성 인식
  • 커뮤니티 레시피 — 사용자 등록 레시피 + 후기·평점
  • 포인트 & 기프티콘 — 출석·요리 인증으로 적립, 카페·편의점 기프티콘 즉시 교환

타겟 사용자

  • 20–40대 자취·1인가구·신혼·요리 입문자
  • 식품·주방용품·배달·HMR에 관심 높은 라이프스타일 소비층
  • 매일 식단·식재료를 결정하는 능동적 사용자
  • 앱 체류 시간 평균 15–30분 (쿠킹 모드 기준)

협업 가능 영역

1. 자체 운영 배너

홈 화면 상단 카드형 배너 노출. 외부 URL · 이벤트 페이지 · 인앱 캠페인 연결 가능. 노출 슬롯 / 기간 협의.

2. 협찬 레시피 (네이티브)

브랜드 식품 · 주방용품 · 식자재를 활용한 레시피를 운영팀이 제작 노출. 사용자 거부감 없는 자연스러운 형태로 배치.

3. 이벤트 / 프로모션 연동

특정 브랜드 챌린지 (예: "○○로 만든 레시피 인증하면 포인트 2배") 등 공동 캠페인 가능.

4. 푸시 알림 캠페인

타겟 사용자 세그먼트에 한정해 브랜드 이벤트 알림 발송 (협의).
